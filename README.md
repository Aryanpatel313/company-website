# Company Website

A professional company website built with HTML, CSS, and JavaScript. Features include:

## Features
- **Responsive Design**: Works perfectly on desktop, tablet, and mobile devices
- **Hero Section**: Eye-catching landing area with call-to-action
- **Services Section**: Showcase your services in an organized grid
- **Projects Section**: Display your best work and projects
- **Contact Form**: Easy way for clients to get in touch
- **Smooth Navigation**: Smooth scrolling between sections
- **Modern Styling**: Clean and professional design

## Sections
1. **Home** - Welcome message and introduction
2. **Services** - 4 service offerings
3. **Projects** - Featured project showcase
4. **Contact** - Contact form for inquiries

## File Structure
- `index.html` - Main HTML file
- `styles.css` - All styling and responsive design
- `script.js` - JavaScript for interactivity and form handling

## How to Use
1. Clone or download this repository
2. Open `index.html` in your web browser
3. Customize the content with your own information
4. Update colors, text, and images as needed

## Customization
- Edit the text in `index.html` to add your own content
- Modify colors in `styles.css` by changing the CSS variables in the `:root` section
- Update social media links in the footer
- Add your own project details and images

## Contact Form
The contact form validates input and logs submissions. To send emails, you'll need to integrate with a backend service like:
- Email service API (SendGrid, Mailgun, etc.)
- Your own backend server
- Third-party form services (Formspree, Netlify Forms, etc.)
